# CANOPY Pre-project Test

CANOPY 프로젝트 시작 전 데이터 및 ML 검증용 개인 작업 저장소.

## Current scope

- AI Hub transportation-mode data audit
- UID-disjoint split validation
- GPS preprocessing experiments
- V3 baseline reproduction
- SpeedTransformer candidate experiments

## Data policy

Raw GPS data, user identifiers, downloaded AI Hub archives, model checkpoints, and secrets are not committed to Git.
